# 风调预顺 WindOps ProofLoop — 作品简介

## 一句话定位

面向风电运维的**可验证闭环工业Agent** — 不只是预测故障，而是自动组织证据、生成方案、执行审批、验证恢复、沉淀知识。

## 目标用户

风电场运维团队（场长、值班工程师、维修班组），每天管理30+台风机，面临告警风暴、诊断延迟、维修决策困难和结果验证缺失。

## 核心痛点

1. **告警泛滥**：单台风机每天产生数十条告警，运维人员难以快速定位根因
2. **决策困难**：维修方案受限于人员、备件、天气等真实资源约束，缺乏量化对比
3. **闭环缺失**：维修完成后无法自动验证恢复效果，事件关闭缺乏证据支撑
4. **知识流失**：每次事故的经验无法有效沉淀和复用

## 解决方案

建立从异常发生到知识沉淀的**完整 ProofLoop 闭环**：

```
异常进入 → 告警智能压缩 → Agent自主调查(SCADA/振动/RUL/知识库)
→ 证据契约(8种类型化证据+完整度评分) → 资源约束决策孪生(MCDM+蒙特卡洛)
→ 策略引擎强制审批(RBAC→风险→前置条件→策略→幂等执行)
→ 携带证明的维修任务包(安全清单+工序+验收标准)
→ 自动恢复验证(Robust Z-Score) → 签发恢复证明 → 审计链记录(SHA-256+Ed25519)
→ 事故复盘知识飞轮(提取→去重→审核→评测→发布)
```

## 技术创新

- **自主调查编排器**：10步可恢复工作流，LLM不可用时自动降级为规则引擎
- **证据契约系统**：8种类型化证据 + 完整度评分 + 新鲜度衰减 + 冲突检测 + 最小确诊门槛
- **资源约束决策孪生**：真实资源查询(人员/备件/天气/RUL)，MCDM多准则+蒙特卡洛置信区间
- **策略强制执行网关**：服务器端RBAC→Preconditions→Policy检查，直接调用API也无法绕过
- **Agent红队测试**：8种工业异常注入场景(传感器离线/LLM超时/告警风暴等) + 自动评分
- **审计签名链**：SHA-256链哈希+Ed25519根签名，中间篡改可检测
- **联邦知识共享**：3个模拟风场，不交换原始SCADA，仅共享统计摘要，支持差分隐私
