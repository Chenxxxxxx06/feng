# 风调预顺 WindOps ProofLoop — 数据来源与合规说明

## 1. 数据来源清单

| 数据源 | 类型 | 许可证 | 用途 | 脱敏状态 |
|--------|------|--------|------|----------|
| CARE Dataset (NREL) | 风机SCADA+故障记录 | CC BY 4.0 | 模型训练、健康评估、RUL预测 | 已匿名化，无PII |
| ERA5 (Copernicus) | 气象再分析数据 | Copernicus License | 风场环境分析 | 公开数据，无PII |

## 2. 脱敏与隐私保护

- **CARE数据集**已由NREL完成匿名化处理，不包含风场名称、GPS坐标、人员信息
- **叶片图像**仅包含风机部件，不含人员面部、车牌等个人身份信息(PII)
- **用户数据**：系统内用户账户仅包含工号/用户名，不存储身份证号、手机号等敏感PII
- **API响应**：策略REG-006强制检查响应中不含PII，非管理员不可见敏感字段

## 3. 商业API使用披露

| API | 提供商 | 用途 | 记录方式 |
|-----|--------|------|----------|
| 通义千问 (DashScope) | 阿里云 | LLM辅助诊断解释生成 | 每次调用记录到审计日志(REG-007) |
| OpenAI API (可选) | OpenAI | 可选LLM后端 | 同上 |

**LLM使用声明**：
- LLM输出仅作辅助参考，不替代专业人员判断 (REG-005)
- LLM输出必须经过策略引擎校验，不能直接变更设备状态 (REG-010)
- LLM不可用时系统自动降级为规则引擎，不阻塞主流程

## 4. 行业风险提示

- 本系统为**辅助决策工具**，所有AI建议需经现场专业人员确认
- 系统设计上禁止直接控制物理设备 (REG-003, REG-008)
- 恢复验证结果需结合现场实际情况综合判断
- 时序因果分析结果标注为"候选因果关系"，不代表确定性因果

## 5. 比赛安全边界

- 不连接真实风机控制器（仅OPC UA模拟服务器）
- 不存储真实风场运营数据
- 不使用真实人员身份信息
- 所有标注`simulated`的数据均为模拟数据，不代表真实工况

## 6. 合规检查引擎

系统内置合规自动巡检引擎 (10条规则，分层管理)：
- **Blocker** (REG-001/003/008/010): 强制执行，违反则阻止操作
- **Critical** (REG-002/004/006/009): 阻止事件关闭
- **Warning** (REG-005): 建议，不阻止操作
- **Info** (REG-007): 自动记录

未经核验的法规引用标记为`unverified`，不作为权威法律结论。
