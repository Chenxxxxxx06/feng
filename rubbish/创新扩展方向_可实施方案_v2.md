### N-11 — Agent数字签名审计链

**一句话**：每个Agent动作用哈希链串联，不可篡改，当场可验证。

**为什么做**：
- 回答评委核心质疑："你怎么证明飞行记录没被篡改？"
- 4-6小时就能实现，技术深度感知极强
- 与IN-06飞行记录器天然配套

**实现方案**：
```python
import hashlib
import json

class AuditChain:
    def __init__(self):
        self.chain = []  # [{action, prev_hash, current_hash, timestamp}]
    
    def append(self, action: dict) -> str:
        prev_hash = self.chain[-1]["current_hash"] if self.chain else "0xGENESIS"
        payload = json.dumps({**action, "prev_hash": prev_hash}, sort_keys=True)
        current_hash = hashlib.sha256(payload.encode()).hexdigest()
        entry = {
            "seq": len(self.chain) + 1,
            "action": action["type"],
            "agent": action.get("agent"),
            "input_hash": action.get("input_hash"),
            "output_hash": action.get("output_hash"),
            "decision": action.get("decision"),
            "prev_hash": prev_hash,
            "current_hash": current_hash,
            "timestamp": action["timestamp"],
        }
        self.chain.append(entry)
        return current_hash
    
    def verify(self) -> bool:
        """重新计算所有哈希，检测篡改"""
        for i, entry in enumerate(self.chain):
            prev = self.chain[i-1]["current_hash"] if i > 0 else "0xGENESIS"
            if entry["prev_hash"] != prev:
                return False
            payload = json.dumps({**entry["action_data"], "prev_hash": prev}, sort_keys=True)
            if hashlib.sha256(payload.encode()).hexdigest() != entry["current_hash"]:
                return False
        return True
```

### N-03 — 人在回路偏好学习与校准

**一句话**：每次人工覆盖Agent决策，系统自动学习偏好，下次更准确。

**为什么做**：
- 直接证明"Agent不是一次性工具，是越用越聪明的系统"
- 量化展示"采纳率从62%提升到84%"
- 与IN-10知识飞轮互补：IN-10学显性规则，N-03学隐性偏好

**实现方案**：

**学习维度**：
| 学习内容 | 输入信号 | 学习方式 |
|----------|----------|----------|
| 方案偏好 | 工程师总是选"降载"而非"停机" | 贝叶斯更新方案先验概率 |
| 人员偏好 | 派张三3次都被改为李四 | 更新人员-任务匹配权重 |
| 时间校准 | Agent估计4h，实际平均8h | 在线更新预估分布参数 |
| 风险偏好 | 工程师接受比Agent建议高10%的风险 | 调整个人风险容忍度参数 |
| 阈值偏好 | 工程师在振动7.5就行动，而非Agent的10.0 | 学习个人判定阈值 |

**数据模型**：
```python
class UserPreferenceProfile:

    # 时间校准因子（个人 vs Agent全局）
    time_calibration_ratio: float  # 实际耗时/Agent预估，默认1.0

    preferred_assignees: Dict[str, float]  # {"task_type": weight}

class AgentCalibrationMetrics:

    total_recommendations: int
    accepted: int
    overridden: int

    avg_override_reason: Dict[str, int]  # {"cost_too_high": 12, "too_aggressive": 8, ...}
```

```python
        # 实际通过中间件拦截后续API调用

    def score_response(self, scenario_key: str, incident_id: str) -> RedTeamScore:

        scenario = self.SCENARIOS[scenario_key]
        actions = self._get_actions_since_injection(incident_id)

        for rule, delta in scenario["score_rules"].items():
            if self._check_rule(rule, actions):
                score += delta
                details.append({"rule": rule, "score": delta, "matched": True})
        return RedTeamScore(
            total=score,
            max_possible=sum(v for v in scenario["score_rules"].values() if v > 0),
            passed=score >= 0,
            details=details,
        )
```

### N-02 — Agent-to-Agent资源协商协议

**一句话**：多个Incident竞争同一稀缺资源时，Agent之间自动协商优先级。

**为什么做**：
- 这是"供应链协同"的Agent化表达——不做ERP，但做Agent协商
- 决赛路演时展示"系统能处理复杂多事件场景"

**核心协议**：
```python
class NegotiationProtocol:
    """
    三步协商：
    1. 声明(Bid): 各Agent声明需求+出价(经济影响)
    2. 匹配(Match): 中央协调器匹配供需
    3. 确认(Commit): 获胜Agent确认，失败Agent升级
    """
    
    async def negotiate(self, resource_id: str, requestors: List[AgentBid]):
        # 第一轮：各自声明
        # Incident #001: "我需要齿轮箱备件，等不了，延迟1天损失¥18,000"
        # Incident #007: "我也需要齿轮箱备件，最多等3天，延迟1天损失¥3,000"
        
        # 比赛规则：经济损失 + 安全风险 + 紧急程度 加权排序
        scores = [self._score_bid(b) for b in requestors]
        winner = requestors[argmax(scores)]
        losers = [b for b in requestors if b != winner]
        
        # 失败者自动升级
        for loser in losers:
            await self._escalate(loser, reason=f"资源{resource_id}已分配给{winner.incident_id}")
        
        return NegotiationResult(
            winner=winner,
            losers=losers,
            reasoning=self._explain_decision(scores),
        )
```

**工作量**：12-16h
- 协商协议引擎：4h
- 资源锁模型：2h
- 升级处理（采购建议/人工仲裁）：3h
- 前端协商可视化：4h

```python
# 症状→基因匹配
def match_fault_genotype(symptoms: dict) -> list[FaultMatch]:
    symptom_vector = extract_feature_vector(symptoms)
    matches = []
    for fault_type, genotype in FAULT_GENOTYPES.items():
        genotype_vector = encode_genotype(genotype)
        similarity = cosine_similarity(symptom_vector, genotype_vector)
        matches.append(FaultMatch(
            fault_type=fault_type,
            similarity=similarity,
            discriminators=genotype["discriminators"],
        ))
    matches.sort(key=lambda m: m.similarity, reverse=True)
    
    # 找出最能区分Top-1和Top-2的鉴别检查
    if len(matches) >= 2 and matches[0].similarity - matches[1].similarity < 0.2:
        top2_diff = set(matches[0].discriminators) ^ set(matches[1].discriminators)
        matches.append(DifferentialDiagnosis(
            recommendation=f"建议进行 {top2_diff} 检查以区分{matches[0].fault_type}和{matches[1].fault_type}"
        ))
    
    return matches
```
