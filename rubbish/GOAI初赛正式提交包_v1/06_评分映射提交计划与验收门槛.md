## 3. 十天冲刺计划

### Day 1｜黄金路径 UI

- 修复调查结果清空；
- 修复 selected 状态刷新；
- 修复 Evidence 刷新；
- 状态机驱动按钮；
- 输出 UI 单元测试。

### Day 2｜后端闭环合同

- 合并旧/新决策入口；
- 持久化恢复证书；
- 修复正向关闭 E2E；
- 保留未验证关闭负例。

### Day 3｜浏览器 E2E 与 Demo 数据

- 修复 8000 端口和 `/api` 前缀；
- 使用独立 Demo DB；
- 登录并访问真实 Incident 页面；
- 连续执行 3 次。

### Day 4｜工程全绿

- 修复 7 个 async 测试；
- ship-gate 不再通过 ignore 隐藏失败；
- 依赖锁定；
- 前端 build、Alembic、测试统一报告。

### Day 5｜安全与合规

- 对齐数据许可和 DOI；
- 选择许可证；
- 添加 LICENSE / NOTICE / third-party 清单；
- 配置 Demo 审计签名；
- 扫描敏感信息。

### Day 6｜产品化最小增量

- 在 Incident 页面接入任务包；
- 接入合规检查；
- What-if 若不稳定则保留路线图；
- 不扩展联邦、OPC 和新算法。

### Day 7｜评测

- 建立 10–30 个固定事件样例；
- 计算任务成功率、危险动作拦截率、证据缺失检出率；
- 记录环境、随机种子和算法版本；
- 不追求虚假的高准确率。

### Day 8｜PPT 与截图

- 以 `02_方案PPT逐页正式内容稿.md` 排版；
- 使用真实页面和测试截图；
- 每个实现状态加标签；
- 删除无法在 30 秒内解释的装饰功能。

### Day 9｜视频

- 按 `03_Demo视频脚本与镜头验收.md` 录制；
- 1080p；
- 字幕、旁白、敏感信息遮挡；
- 让未参与开发的人复现一次。

### Day 10｜红队审稿与提交

- 逐页做“证据在哪里”追问；
- 核对 500 字限制；
- 核对团队最多 3 人；
- 核对链接权限；
- 最终 PDF 字体嵌入；
- 上传后下载回验。

## 6. 最后红线

- 不写无来源的行业损失金额；
- 不把固定 Demo 数字当统计结果；
- 不把模拟 OPC 说成已接真实风机；
- 不把固定 YOLO 返回说成真实推理；
- 不把内存联邦模拟说成跨场站生产部署；
- 不把哈希链说成区块链；
- 不配置签名密钥时不说“Ed25519 已验证”；
- 不把被 ship-gate 忽略的测试说成全量通过；
- 不在许可证未落地时说“已按 Apache 2.0 开源”；
- 不把超过 3 人写进正式参赛成员。
