## 🟢 第三批：复赛加分（工作量大些 | 9月3日前）

### B9 — OPC UA 数字影子网关 IN-07
- **工作量**: 18h
- **创新点**: IT/OT融合，设备主动驱动Agent
- **实现**:
  - Python `asyncua` 本地模拟服务器（1台风机，6-10个节点）
  - FastAPI后台OPC Client：连接状态、安全策略、证书
  - 地址空间浏览器 + 语义映射（OPC节点→风机/部件/测点）
  - 订阅值变化 → 超阈值触发Incident自动创建
  - 写操作仅发到ControlSandbox节点，经策略引擎判定
  - 前端OT连接页面：Endpoint列表 + 节点树 + 实时值 + 质量码
- **Demo亮点**: 模拟齿轮箱振动从正常→超标→系统自动创建Incident→策略引擎阻止真实控制→只写到沙箱
- **ADR必需**: 说明"为什么做/为什么只做这些/真实生产还缺什么"
- **依赖**: 无
- **状态**: 待开始

### B10 — 事故复盘知识飞轮 IN-10
- **工作量**: 8h
- **创新点**: 事件关闭后自动生成复盘，提取候选知识，形成学习闭环

- **Demo亮点**: 系统不仅诊断，还能"越用越聪明"
- **依赖**: 无
