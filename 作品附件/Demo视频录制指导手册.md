## 二、录制前准备（必做！）

### 2.1 环境确认

```bash
# 1. 确保后端启动成功
cd backend && python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
# 访问 http://127.0.0.1:8000/api/health → {"status":"ok"}

# 2. 确保前端构建完成（后端直接托管前端）
cd frontend && npm run build
# 访问 http://127.0.0.1:8000 → 看到登录页

# 3. 确认数据库有种子数据
python -m scripts.seed_data
```

## 六、常见问题预案

**Q: 评委会觉得我们只做了设备诊断，没做供应链？**

A: 视频中要在旁白里明确说明"系统覆盖设备诊断、工单调度、备件库存联动和供应链风险预警多个方向"，并展示工单中备件字段的自动填充。后续可以在"后续扩展计划"中说明库存和供应链模块的开发路线图。

**Q: 5分钟够展示所有功能吗？**

A: 不要平均分配时间。镜头3（AI诊断）和镜头7（3D孪生）是最核心的差异化亮点，各自给足60秒和30秒。镜头8-9可以快速闪过，不用停留太久。总共4分50秒刚好。

**Q: 旁白怎么录？先录画面还是先录声音？**

A: 建议**先录制画面+鼠标操作**，然后在OBS中叠加录制旁白。这样旁白可以精准配合画面节奏，不会出现嘴快于手或手快于嘴的情况。

**Q: 需要加字幕吗？**

A: 强烈建议加上字幕。初赛评委可能一次性看几十个视频，字幕能确保即使音频不清晰也能传达核心信息。可以用剪映自动生成然后手动校对。
